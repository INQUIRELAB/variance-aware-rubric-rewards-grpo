# Dataset Card: Heart-Related RaR-Medicine with Synthetic Reasoning

## Overview

This dataset is a filtered and augmented subset of [RaR-Medicine](https://huggingface.co/datasets/google/rar-medicine) that contains 2,206 heart-related medical question-answer pairs with rubric annotations and synthetic reasoning traces. Each record includes a clinical question, a reference answer, a set of signed rubric criteria for evaluation, and a step-by-step reasoning trace generated by MedGemma 3:27B.

The dataset was created to support rubric-based reinforcement learning for heart-focused medical question answering. It serves as the training data for the GRPO pipeline described in "Improving Heart-Focused Medical Question Answering in LLMs via Variance-Aware Rubric Rewards with GRPO."

## Split Distribution

| Split | Count |
|-------|-------|
| train | 1,808 |
| val   | 204   |
| test  | 194   |

The train split is further divided 50/50 into disjoint subsets for supervised fine-tuning (SFT) and GRPO training. The val and test splits are not used during training.

## Heart Themes

All 2,206 records are classified as heart-related (`heart_related = "YES"`). The dataset spans 14 cardiac themes:

| Theme | Description |
|-------|-------------|
| Cardiac Medications | Drug interactions, prescribing, side effects |
| Cardiomyopathy | Heart muscle diseases |
| Cardiovascular Disease | General cardiovascular conditions |
| Cardiovascular Risk Factors | Risk stratification and prevention |
| Chest Pain | Differential diagnosis for chest pain |
| Congenital Heart Disease | Structural heart defects from birth |
| Coronary Artery Disease | Atherosclerosis and related conditions |
| ECG/EKG Interpretation | Electrocardiogram analysis |
| Heart Attack (Myocardial Infarction) | Acute myocardial events and management |
| Heart Failure | Systolic and diastolic heart failure |
| Heart Palpitations | Evaluation of palpitation symptoms |
| Heart Rhythm Disorders (Arrhythmia) | Atrial fibrillation, tachycardia, etc. |
| Heart Valve Problems | Valvular heart diseases |
| High Blood Pressure (Hypertension) | Hypertension management and complications |

## Schema

Each JSONL record contains 16 fields:

| Field | Type | Description |
|-------|------|-------------|
| `question` | string | The original medical question |
| `reference_answer` | string | Clinician-authored reference answer |
| `question_source` | string | Source dataset for the question |
| `rubric_count` | integer | Number of rubric criteria for this question |
| `split` | string | Dataset split: `train`, `val`, or `test` |
| `prompt` | list[dict] | Chat-formatted prompt with `role` and `content` fields |
| `completion` | string | Reference completion (same as `reference_answer`) |
| `rubrics` | list[dict] | List of rubric objects, each with `criterion` (string), `points` (signed integer), and `title` (string) |
| `heart_related` | string | Always `"YES"` in this dataset |
| `heart_theme` | string | One of the 14 cardiac themes listed above |
| `llm_keywords` | string | Keywords extracted by the LLM classifier |
| `verified_keywords` | string | Keywords verified against the original question text |
| `keyword_verification_status` | string | Verification result (e.g., `"FULLY_VERIFIED"`) |
| `classification_confidence` | string | Classifier confidence level (e.g., `"HIGH"`) |
| `synthetic_reasoning` | string | MedGemma-generated reasoning trace connecting the question to the reference answer |
| `reasoning_generation_timestamp` | string | ISO 8601 timestamp of when the reasoning trace was generated |

## Rubric Structure

Each rubric criterion has three fields:

```json
{
  "criterion": "Essential Criteria: Identifies mechanical thrombectomy as the appropriate treatment.",
  "points": 5,
  "title": "Identifies Treatment"
}
```

Positive `points` values encode desirable behaviors that a response should satisfy. Negative `points` values encode undesirable behaviors that a response should avoid (e.g., pitfall criteria with `points = -2`). The rubric structure directly supports the reward computation in GRPO training: a judge model evaluates each criterion independently and produces binary present/absent decisions, which are then aggregated into a scalar reward.

## Data Provenance

The original questions and reference answers come from [RaR-Medicine](https://huggingface.co/datasets/google/rar-medicine). Heart-related filtering was performed using a MedGemma 3:27B classifier that assigns a binary heart-related label, a theme category, and keyword evidence. A keyword verification step confirms that the classifier's decisions are traceable to actual content in the question text. Synthetic reasoning traces were generated by MedGemma 3:27B in a separate pass, aligned with the reference answer for each question.

## Intended Use

This dataset is intended for research on rubric-based reinforcement learning for medical question answering. It should not be used for direct clinical decision-making without further validation and clinician oversight.
